## 🎯 Phase 3 중점 검수 목표

사용자가 탐색 탭을 통해 최적의 배당 상품을 직관적으로 발굴하고, ETF 모달에서 핵심 정보(수수료, 구성종목)를 확인한 뒤, **파이어(FIRE) 역산 시뮬레이터**에서 목표 월 배당금(30만~500만 원)을 달성하기 위한 필요 투자금과 세후 배당금을 수학적 오차 없이 실시간으로 계산·시뮬레이션할 수 있는지를 정량적으로 검증합니다.

## 📋 세부 검수 항목 및 판정 기준 (Acceptance Criteria)

### 1. [기능 1] 상단 큐레이션 3대 탭 및 시장 토글 필터링
- [ ] **1-1. 3대 큐레이션 탭 필터링 정합성:**
  - **`🔥 인기 월배당 TOP 10` 탭:** `assetType === 'ETF' && dividendCycle === 'MONTHLY'` 조건으로 필터링 후 `popularityScore` 기준 상위 10개 종목이 정확히 노출되는가?
  - **`💰 고배당 6%+ 알짜` 탭:** `dividendYield >= 6.0` 종목을 대상으로 정렬되어 배당수익률 6% 이상 알짜 종목들이 누락 없이 표출되는가?
  - **`🏛️ 시총 상위 대표주` 탭:** `marketCap` 내림차순 정렬로 시장을 대표하는 초대형 우량 배당주(삼성전자, 애플, MSFT, SPY 등)가 상위 랭크되는가?
- [ ] **1-2. 시장 토글 필터 (ALL / KR / US):**
  - 전체 / 국내 / 미국 토글 전환 시 깜빡임이나 레이아웃 틀어짐 없이 0.1초 내 즉각적인 필터링 렌더링이 이루어지는가?

### 2. [기능 2] ETF 상세 정보 모달 / 드로어 및 포트폴리오 연동
- [ ] **2-1. 모달 렌더링 필수 항목:**
  - 종목 카드 클릭 시 모달/드로어가 부드럽게 오픈되는가?
  - **운용보수(수수료):** `expenseRatio` 수치가 퍼센트(%) 단위로 정확히 표시되는가?
  - **배당주기:** 월배당 / 분기배당 표기 일치 여부.
  - **상위 편입종목 3개:** `topHoldingsAvailable === true`인 경우 상위 3~5개 보유종목 칩(태그)이 정상 표출되고, `false`인 경우 "상세 구성 종목 정보 준비 중" 안내가 투명하게 렌더링되는가?
- [ ] **2-2. `[+ 포트폴리오에 담기]` 바구니 연동:**
  - 모달 내 담기 버튼 클릭 시 하단 파이어 시뮬레이터 선택 목록(Basket)에 즉시 추가/제거 상태가 동기화되는가?
  - 이미 담긴 종목은 `[담김 / 제거]` 상태로 토글 전환되는가?

### 3. [기능 3] 파이어(FIRE) 역산 시뮬레이터 수학적 계산 정합성
- [ ] **3-1. 슬라이더 인터랙션:**
  - 목표 월 배당금 슬라이더가 **월 30만 원 ~ 월 500만 원** 범위에서 렉(Jank) 없이 60fps로 매끄럽게 조절되는가? (기본 추천값: 월 100만 원)
- [ ] **3-2. 수학적 역산 공식 및 단주 오차 한도 검증:**
  - **공식 정의:**
    $$\text{목표 연간 세후 배당금} = \text{목표 월 배당금} \times 12$$
    $$\text{종목별 세후 DPS} = \text{DPS} \times (1 - \text{세율})$$
    $$\text{필요 주식 수} = \left\lceil \frac{\text{목표 연간 세후 배당금} \times \text{비중}}{\text{종목별 세후 DPS}} \right\rceil$$
    $$\text{실제 세후 연 배당금} = \sum (\text{필요 주식 수} \times \text{세후 DPS})$$
    $$\text{필요 투자 자본} = \sum (\text{필요 주식 수} \times \text{현재가})$$
  - **정량적 오차 허용 기준:**  
    $$\left| \text{실제 세후 연 배당금} - \text{목표 연간 세후 배당금} \right| \le 10,000\text{원}\ (\text{주 단위 올림 오차만 허용})$$
- [ ] **3-3. 세금 계산 분기 정밀도:**
  - **국내 주식 / ETF:** 배당소득세 **15.4%** (소득세 14% + 지방소득세 1.4%) 정확 분기.
  - **미국 주식 / ETF:** 현지 원천징수세율 **15.0%** 정확 분기.
- [ ] **3-4. 금융소득종합과세 경고 박스 노출:**
  - 포트폴리오의 연간 세전 배당금 합계가 **2,000만 원을 초과**할 경우, 눈에 띄는 노란색 경고 카드(금융소득종합과세 대상 안내 박스)가 즉시 노출되는가?

### 4. 반응형 뷰포트 & 가로 스크롤 방지
- [ ] **4-1. 375px 모바일 뷰포트 최적화:**
  - iPhone SE (375px) 환경에서 슬라이더, 모달, 탭 버튼, 시뮬레이터 카드에서 가로 스크롤(Horizontal Overflow) 현상이 0건인가?
- [ ] **4-2. 컨테이너 규격 유지:**
  - 데스크톱에서도 `max-w-xl(640px)` 중앙 정렬 컨테이너가 흔들림 없이 유지되는가?

### 5. 빌드 및 에러 무결성
