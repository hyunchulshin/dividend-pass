# 🚀 배당패스 (Dividend Pass) 종합 마일스톤 & 정량적 합격 기준서

> **프로젝트 개요:**  
> `cheongyak-pass.vercel.app` 스타일의 로그인 없는 초경량 모던 핀테크 웹 서비스.  
> 대중의 호기심을 자극하는 **"인기 월배당 ETF 큐레이션"**과 **"월 100만 원 배당 파이어 역산 시뮬레이터"**를 완전 무인 파이프라인으로 구현.

---

| 역할 | 에이전트명 (Pane) | 엔진 & 추론 레벨 | 핵심 임무 |
| :---: | :---: | :---: | :--- |

## 2. PM 게이트키핑 & 피드백 루프 프로토콜

각 단계는 DEV 작업이 끝났다고 바로 다음 단계로 넘어가지 않으며, **엄격한 QA 검수와 PM의 승인(Sign-off)**을 거쳐야만 전환됩니다.

```mermaid
flowchart TD
    Start[Phase 시작] --> DevWork[DEV 작업 수행 (stock_dev)]
    DevWork --> QAReview[QA 검수 수행 (stock_qa)]
    QAReview --> Check{QA 검수 결과}
    Check -- "ISSUE / FAIL 발견" --> PMReview[PM 피드백 조율 및 보완 지시서 발행]
    PMReview --> DevWork
    Check -- "100% PASS" --> PMSignoff[PM 최종 완료 확정 (Sign-off)]
    PMSignoff --> NextPhase[다음 Phase 착수]
```

1. **DEV 완료 보고:** `stock_dev`가 해당 마일스톤의 개발 완료를 보고하면, PM이 `stock_qa`에게 검수 체크리스트를 전달하고 테스트를 지시합니다.
2. **QA 검수 보고:** `stock_qa`가 정량적 기준을 검증하고 `PASS / FAIL` 리포트를 PM에게 보고합니다.
3. **PM 피드백 조율 (결함 발견 시):**
   - 사소한 취향 문제가 아닌, 기획 및 데이터의 본질적 결함인지 PM이 판단합니다.
   - PM이 명확한 원인과 수정 가이드를 정리하여 `stock_dev`에게 **[보완 지시서]**를 하달합니다.
   - 보완 완료 후 `stock_qa`가 재검증(Regression Test)을 수행합니다.
4. **PM 최종 완료 확정:** 모든 기준이 **100% 합격**했을 때만 PM이 단계 완료를 선언하고 다음 단계로 진입합니다.

## 3. 단계별 상세 목표 및 명확한 달성 기준 (Acceptance Criteria)

---

### [Phase 1] 백엔드 데이터 파이프라인 구축 & 500개 종목 데이터셋 생성

#### 🎯 목표
- 무료 API(`yfinance` + 네이버 모바일 엔드포인트)를 통해 500개 핵심 배당주/ETF 데이터를 수집하고, TTM 배당률 및 인기점수를 산출하여 `public/data/dividend_stocks_500.json` 단일 파일로 빌드하는 완전 자동화 파이프라인 완성.

#### 📋 정량적 달성 기준 (Acceptance Criteria - Pass/Fail)
- [ ] **데이터 볼륨 및 균형:**
  - `dividend_stocks_500.json` 내 총 종목 수가 **정확히 500개**여야 함 (국내 250개: 주식 150 + ETF 100 / 미국 250개: 주식 150 + ETF 100).
- [ ] **스키마 무결성 (결측치 0건):**
  - 모든 종목에 `ticker`, `name`, `market` (KR/US), `price`, `dpsTtm`, `dividendYield`, `dividendCycle` (MONTHLY/QUARTERLY/ANNUAL), `marketCap`, `volume`, `popularityScore`, `isHighRisk` 필드가 존재해야 하며, `null`이나 `NaN`, `undefined`가 0건이어야 함.
- [ ] **안전 필터링 작동 검증:**
  - 시가총액 1,000억 원(미국 $500M) 미만 종목이 0건이어야 함.
  - TTM 배당수익률 20% 초과 종목은 예외 없이 `isHighRisk: true` 플래그가 정확히 부착되어야 함.
- [ ] **인기 점수(Popularity Score) 정합성:**
  - `(AUM 60% + 일평균 거래대금 40%)` 공식으로 산출된 인기 점수 1~10위에 시장 대표 월배당 ETF(예: SOL 미국배당다우존스, TIGER 미국배당다우존스, JEPI 등)가 정상 배치되어야 함.
- [ ] **실행 성능:**
  - 500개 종목 데이터 수집 및 JSON 생성 스크립트의 실행 시간이 **3분 이내**여야 함.

### [Phase 2] 프론트엔드 프로젝트 셋업 & 디자인 시스템 (`cheongyak-pass` 스타일)

#### 🎯 목표
- Next.js (App Router) + Tailwind CSS 기반의 모바일 퍼스트 핀테크 UI 토대를 구축하고, 투명성을 보장하는 물음표(?) 툴팁 컴포넌트를 완성.

#### 📋 정량적 달성 기준 (Acceptance Criteria - Pass/Fail)
- [ ] **빌드 및 에러 무결성:**
  - `npm run build` 시 타입스크립트 및 린트 에러 0건.
- [ ] **반응형 뷰포트 최적화:**
  - 모바일(375px 아이폰 SE, 390px 아이폰 14, 430px 프로맥스)에서 **가로 스크롤(Horizontal Overflow) 현상이 0건**이어야 함.
  - 최대 폭 `max-w-xl(640px)` 중앙 정렬 컨테이너로 데스크톱에서도 모바일 앱 같은 정갈함 유지.
- [ ] **디자인 통일성 (`cheongyak-pass` 벤치마크):**
  - 부드러운 슬레이트 배경(`bg-slate-50`), 모던 라운드 카드(`rounded-2xl`), 서브 텍스트 가독성(`text-slate-500`), 신뢰감을 주는 블루/에메랄드 뱃지 시스템 구축.
- [ ] **물음표(?) 툴팁/팝오버 컴포넌트 (`InfoTooltip`):**
  - **모바일:** 터치 시 즉시 설명 팝오버 오픈, 외부 영역 탭 시 닫힘.
  - **데스크톱:** 마우스 호버 시 0.1초 내 툴팁 표시.
  - **내용 완비:** 인기 점수 계산식, TTM 배당률 개념, 안전 필터링 기준이 등록되어 정상 렌더링되어야 함.

### [Phase 3] 메인 3대 기능 구현 (탐색 탭 + ETF 모달 + 파이어 역산기)

#### 🎯 목표
- 사용자가 5분 이상 이탈하지 않고 탐색하고 시뮬레이션할 수 있는 3단계 핵심 인터랙티브 기능 완성.

#### 📋 정량적 달성 기준 (Acceptance Criteria - Pass/Fail)
- [ ] **[기능 1] 상단 큐레이션 탭 및 필터:**
  - `🔥 인기 월배당 TOP 10`, `💰 고배당 6%+ 알짜`, `🏛️ 시총 상위 대표주` 탭 전환 시 화면 깜빡임 없이 즉시 렌더링.
  - 국내/미국 토글 필터 정상 동작.
- [ ] **[기능 2] ETF 상세 정보 모달/드로어:**
  - 종목 카드 클릭 시 운용보수(수수료), 배당주기(월/분기), 기초지수, 상위 편입종목 3개가 정확히 표시되어야 함.
  - `[+ 포트폴리오에 담기]` 클릭 시 하단 바구니에 즉시 추가/제거 연동.
- [ ] **[기능 3] 파이어 역산 시뮬레이터 (수학적 정합성):**
  - 목표 월 배당금 슬라이더(월 30만 원 ~ 월 500만 원) 및 종목별 비중 조절 기능 완비.
  - **수학적 오차 검증:**  
    $$\left| \sum (\text{역산된 주식 수} \times \text{주당 배당금}) \times (1 - \text{세율}) - \text{목표 연 배당금} \right| \le 10,000\text{원}\ (\text{주 단위 절상 오차만 허용})$$
  - 세금 분기: 국내 종목 15.4%, 미국 종목 15.0% 분기 계산 정확도 100%.
  - 금융소득종합과세: 연간 배당금 합계 2,000만 원 초과 시 경고 배지(노란색 카드) 노출.
- [ ] **인터랙션 성능:**
  - 슬라이더 드래그 시 렉(Jank) 없이 부드러운 상태 업데이트(60fps) 유지.

### [Phase 4] 1일 1회 무인 자동 갱신 워크플로우 & 최종 E2E 배포 검증

#### 🎯 목표
- 서버 비용 0원으로 매일 아침 최신 시세와 배당률이 갱신되는 완전 무인 배포 시스템 완성.

#### 📋 정량적 달성 기준 (Acceptance Criteria - Pass/Fail)
- [ ] **GitHub Actions 워크플로우 검증:**
  - `.github/workflows/daily_sync.yml` 파일 작성 (매일 07:00 KST 크론 스케줄).
  - 수동 트리거(`workflow_dispatch`) 실행 시 오류 없이 데이터 수집 $\rightarrow$ JSON 업데이트 $\rightarrow$ 자동 커밋까지 완주.
- [ ] **프로덕션 빌드 및 런타임 무결성:**
  - `npm run build` 성공 및 `next start` 환경에서 콘솔 경고/에러 0건.
  - Vercel 배포 준비 완료 (환경변수나 비밀키 없이도 무중단 빌드 가능).
- [ ] **페이지 로딩 성능:**
  - 정적 JSON 로딩 기반으로 최초 페이지 로딩(LCP)이 **1.5초 이내**여야 함.
