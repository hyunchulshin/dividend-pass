# 💰 배당패스 (Dividend Pass)

> **"월 100만 원 배당을 받으려면 어떤 종목을 몇 주 사야 할까?"**  
> 복잡한 로그인이나 유료 결제 없이, **3초 만에 역산**해 주는 초경량 모바일 퍼스트 고배당 포트폴리오 웹 도구

---

## ✨ 핵심 기능

1. **🔥 2026 지금 가장 인기 있는 월배당 ETF TOP 10 큐레이션**
   - 시가총액(60%) + 일평균 거래대금(40%) 순수 공식 기반 투명한 랭킹
   - 한국/미국 시장의 대표 고배당 및 월배당 ETF 실시간 큐레이션
   - 상장 1년 미만 신규 상장 ETF의 분배금 연환산(Annualized) 보정 알고리즘 적용
2. **💎 500개 고배당주/ETF 데이터셋 탐색**
   - 미국 & 한국 주식/ETF 500개 종목의 TTM 배당수익률, 배당주기, 운용보수, 상위 편입종목 정보
3. **🧮 파이어(FIRE) 배당 역산 시뮬레이터**
   - 원하는 "목표 월 배당금" 입력 시, 포트폴리오 구성에 따른 필요 총 자본 및 종목별 매수 수량 자동 계산
   - 일반 배당소득세(15.4% / 15.0%) 및 금융소득종합과세(2,000만 원 초과 경고) 정밀 반영
4. **❓ 투명한 물음표(?) 툴팁 시스템**
   - 인기 점수 산출 공식, TTM 개념, 안전 필터(시총/거래대금/무배당 배제) 기준을 사용자가 직접 확인 가능

## 🛠 Tech Stack

- **Frontend:** Next.js 14+ (App Router), TypeScript, Tailwind CSS, Lucide React
- **Data Pipeline:** Python 3.11+, yfinance, Requests (GitHub Actions 일일 정기 갱신)
- **Deployment:** Vercel
